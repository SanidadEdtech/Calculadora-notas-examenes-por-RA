# Calculadora de notas por Resultados de Aprendizaje

Herramienta para docentes de FP que reparte las preguntas de un examen entre Resultados de Aprendizaje (RA) y calcula la nota de cada RA.

> **EN** · Tool for vocational teachers that maps exam questions to learning outcomes and calculates the grade for each one.

🔗 **Demo:** [calculadorara.sanidadedtech.es](https://calculadorara.sanidadedtech.es/)

## Para quién es

Profesorado de Formación Profesional.

## Qué incluye

- Configuración del examen
- Asignación de preguntas por RA
- Introducción de notas y resultados finales por RA

## Tecnología

- Página única en HTML, CSS y JavaScript, sin frameworks ni proceso de compilación.
- Diseño adaptable a móvil.
- Publicado con GitHub Pages.
- Desarrollado mediante *AI-driven prototyping*: diseño pedagógico y clínico propio, construcción asistida por IA y revisión manual.

## Uso

Abre la demo en el navegador o descarga `index.html` y ábrelo directamente: no necesita instalación.
